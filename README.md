# MLBB Esports Team Website

A professional esports team website for Mobile Legends: Bang Bang with 3D effects, silver/gold theme, and RVC CD design.

## Features

- 🎮 3D Hero Scene with RVC CD (Rotating Video Cube CD)
- 🏆 Dynamic Player Management
- 📊 Match Management System
- 📸 Media Gallery with Cloudinary integration
- 🎨 Silver & Gold Theme
- 🔐 Secure Admin Panel with JWT authentication
- 📱 Fully Responsive Design
- ⚡ Optimized for Vercel Deployment
- 🎯 Three.js 3D Effects throughout
